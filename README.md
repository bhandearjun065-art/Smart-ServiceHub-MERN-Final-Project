# Smart ServiceHub

A modern MERN-style service booking platform with a customer portal, admin dashboard, responsive UI, glassmorphism, gradients, micro-interactions and animated sections.

## Included
- React + Vite frontend
- Node + Express backend starter
- MongoDB/Mongoose model examples
- JWT-ready authentication structure
- Service browsing and booking UI
- Admin dashboard UI
- Responsive navigation
- Modern animations using CSS
- Clean folder structure

## Run
### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```

Create `backend/.env` from `.env.example`.

The frontend currently includes demo data so the UI can be explored immediately. API integration points are included in `frontend/src/services/api.js`.
